How to use the scanner

Before exam

  1. Open the template editor to customise the sheet title, school / department heading, shading instructions, and index number instructions. Select Show school heading if you want that heading printed; it is invisible in the original template.
  2. Check the Live print preview. Text wraps inside the original instruction boxes and shrinks to fit. If a fit warning appears, shorten the text or remove blank lines before downloading. All bubbles, tables, and registration marks remain in their original positions.
  3. Click Download PDF in the editor, then print the downloaded sheet on A4 at Actual size / 100%. Check a printed copy before making the full set. You can also print the unchanged optical mark sheet template.
  4. The editor saves your text in the current browser. Use Restore original to return to the supplied template text. The sheet title in the editor is separate from the Exam paper title used for scanner reports; set both as needed.
  5. Set the correct answer key in the app, confirm the number of questions, and save it before the exam starts.
  6. Expand Step 1: Upload student directory above the answer key, then click Download student CSV template. Fill in the CLASS, STUDENT, and ID columns, then use Upload student CSV. Keep four-character IDs as text in your spreadsheet. Check the loaded student count and list before processing; a successful upload is saved in this browser and replaces the previous directory.
  7. Use the calibration page if the sheet layout needs adjusting for a different printout or scanner setup.

During exam

  1. Distribute the answer sheets and instruct students to fill in their IDs and answers carefully.
  2. Students must shade their index number in the format Class + number, for example 2E05 or 1A12, using the correct letter and two-digit number.
  3. Collect the completed sheets and scan them as PDF files into the app.
  4. Process the PDF files, then review each sheet using the next/previous controls and the name search to confirm student IDs.
  5. Correct any wrong or missing student IDs or answer selections before final scoring.

After exam

  1. Review the score summary and student reports to check for any incorrect markings or matching issues.
  2. Use question analysis or edit results to fix errors and then save the final data.
  3. Export the results as CSV, download raw scan data, or print individual or all student reports.
  4. Archive the final result files and keep the answer key for future reference or moderation.

Your data stays on your device. Uploaded student lists and scanned answer sheets are processed locally in your browser. Their contents are not uploaded to the internet or sent to a server. Saved student lists, answer keys, and results are stored only in this browser, not in cloud storage. Use Start afresh to clear this app’s saved data. Downloaded files remain on your device.

1 Upload student directory First-time setup

Complete this setup once before your first use. Download the CSV template, fill in your students, and upload the completed file. Your saved directory loads automatically on future visits in this browser.

Private and local: Your CSV is read and saved in this browser only. Student names and IDs are not sent to a server.

Required columns: CLASS, STUDENT, ID. Use one row per student, for example 1A,Alex Tan,1A01. IDs must be unique and exactly four letters or digits; the first two characters identify the class. In Excel, format the ID column as Text before entering IDs to preserve values such as 0501 and 2E05, then save as CSV UTF-8.

You do not need to upload the list for every exam. Reopen this section only to update your student list, or to set it up again in a different browser or after clearing saved data. A new upload replaces the saved directory. This version stores its directory, answer key, and results separately from the original scanner.
